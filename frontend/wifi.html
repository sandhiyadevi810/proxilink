How Wi-Fi P2P Works in ProxiLink

• Browser WebRTC P2P: Devices connected to the same Wi-Fi network exchange lightweight SDP offers/answers over local WebSocket signalling, then form a direct, encrypted RTCDataChannel with zero internet data consumption.
• Router-Free Wi-Fi Direct: Web browsers cannot directly access low-level Wi-Fi Direct radio chips due to operating system sandbox restrictions. For true infrastructure-less peer discovery without an access point, ProxiLink provides the native Android service in android/WiFiDirectTransferService.kt.
