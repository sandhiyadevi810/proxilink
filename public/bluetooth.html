⚠ Important: Web Bluetooth Limitations

  • Only Bluetooth Low Energy (BLE) is accessible from browsers — not Classic Bluetooth.
  • Maximum reliable data per write: ~512 bytes (BLE MTU limit). Not suitable for large files.
  • Only works in Google Chrome. Firefox, Safari, and iOS Chrome do not support Web Bluetooth.
  • Apple iOS devices cannot use this feature — Apple restricts Web Bluetooth in Safari and iOS Chrome.
  • The browser requires a user gesture to initiate Bluetooth scanning.
  • For Wi-Fi Direct or Classic Bluetooth file transfer, a native Android app is required.
